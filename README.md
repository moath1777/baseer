# بصير | Baseer

منصة Next.js لإدارة الاستراتيجية والأداء المؤسسي وفق متطلبات v06 (23 شريحة).
أغلقت M1 كخط أساس للتصميم بتوجيه المستخدم في 14 أكتوبر 2026. اكتملت M2 تقنيًا ونشرت: قاعدة بيانات، حسابات، صلاحيات وهيكل قابل للإدارة. [المنصة المنشورة](https://baseer.moath1777.workers.dev/overview)، و[نتائج التحقق وحدود التسليم](docs/IMPLEMENTATION-STATUS.md).

## التشغيل المحلي

المتطلبات: Node.js 24 وnpm. قاعدة D1 المحلية منفصلة عن السحابة.

```bash
npm ci
npm run db:migrate
npm run dev -- --port 3001
```

افتح [مساحة العمل](http://127.0.0.1:3001/overview). التسجيل بالبريد وكلمة المرور فقط، دون OTP أو إرسال بريد. الحساب الجديد لا يملك صلاحيات حتى إسنادها من المدير. لا يوجد مدير افتراضي أو كلمة مرور ثابتة في المستودع.

لإنشاء المدير الأول (بريد جديد غير مسجل):

```bash
npm run admin:bootstrap -- --email admin@example.com --name "Administrator" --local
```

استبدل البريد ببريد المسؤول الفعلي. تحفظ بيانات الدخول داخل artifacts/m2 في ملف مستبعد من Git. الكلمة المولدة تلقائيًا مؤقتة وتتطلب التغيير عند أول دخول. عند تمرير كلمة اختارها صاحب الحساب عبر --password-stdin، تعتمد ككلمة دائمة دون طلب تغييرها. لا يعيد الأمر تعيين حساب موجود. يمكن للمدير إدارة المستخدمين من صفحة الحساب وإدارة الوصول؛ تغييرات الصلاحيات وتعطيل الحساب وإعادة تعيين كلمته تبطل جلساته. يستطيع مدير الحسابات حذف حساب آخر بعد التأكيد، فتزال صلاحياته وجلساته مع الاحتفاظ ببيانات العمل وسجل التدقيق؛ لا يسمح بحذف الحساب الحالي أو آخر مدير نشط.

## نطاق M2

- حسابات بكلمات مرور مجزأة وجلسات HttpOnly قابلة للإبطال ومحددة بثماني ساعات.
- تسعة أدوار مع نطاق جهة ووحدة تنظيمية يشمل وحداتها التابعة وتصريح صريح للسجلات المقيدة.
- وحدات، استراتيجيات فرعية، خطط، أهداف، مبادرات وارتباطات مؤشرات، مع رؤية ورسالة وقيم وفترات ومسؤوليات.
- تعديل وحذف مقيد بالتبعيات، ومنع الدورات والروابط عبر الجهات والتحديث المتعارض.
- عروض الخريطة والتنظيمي والشجري وملخص أعداد الهيكل من قاعدة البيانات نفسها.
- سجل تدقيق دائم يتضمن قبل/بعد مع كل عملية حفظ في معاملة واحدة، وتمنع مشغلات قاعدة البيانات تعديله عبر التطبيق.
- واجهة عربية وإنجليزية متجاوبة.

تعريف المؤشر الكامل ومعادلاته وقياساته وموافقاته والتقارير الرسمية تبقى M3–M6. ارتباط المؤشر في M2 ليس بطاقة قياس مكتملة. تبقى سياسات الأعمال التي لم تعتمدها الجهة بوابات قبول للمراحل المعنية.

## نموذج M1 المحفوظ

[معاينة M1](http://127.0.0.1:3001/preview/overview) تحتفظ بالشاشات التجريبية وبيانات localStorage. معاينة الأدوار فيها لا تمنح أي صلاحية لمساحة M2. لا تنسخ بيانات المعاينة إلى قاعدة البيانات تلقائيًا. صفحة المعاينة العامة لا تقرأ بيانات الحسابات أو الهيكل الفعلي.

## التحقق

```bash
npm run typecheck
npm test
npm run build:cloudflare
npm run preview:cloudflare
```

الاختبارات تشمل قواعد نموذج M1 واختبارات M2 ضد محاكي D1: العزل والسرية، الأدوار، الجلسات، العلاقات، الحفظ، التزامن والتراجع عن العمليات الفاشلة. لا تعتمد اختبارات M2 على بيانات السحابة أو بيانات المستخدم.

أوقف خادم التطوير قبل بناء OpenNext على Windows إذا كانت ملفاته قيد الاستخدام.

## Cloudflare

قاعدة D1 باسم baseer-m2 منشأة ومربوطة باسم DB في wrangler.jsonc، والهجرة مطبقة والمدير الأول معد على البيئة الحالية. لتحديث النشر بعد تسجيل دخول المشغل:

```bash
npm run db:migrate:remote
npm run build:cloudflare
npm run deploy:cloudflare
```

لبيئة مستقلة جديدة، أنشئ قاعدة D1 وحدّث معرفها وإعداد Worker ثم طبق الهجرة واستخدم admin:bootstrap مع --remote لإعداد مدير جديد. لا تعد إنشاء قاعدة البيئة الحالية. تطبق الهجرة قبل النشر، ولا يرفع ملف بيانات الدخول أو ملفات PowerPoint. لا يتطلب تسجيل الدخول مزود رسائل أو مفاتيح بريد. الربط المؤسسي SSO مؤجل بطلب المستخدم؛ يمكن ربط مزود خارجي لاحقًا بمعرف الحساب الداخلي نفسه، وهو ليس موصلًا منفذًا الآن.

اختبار القبول السحابي الاختياري: `node scripts/smoke-deployed.mjs --url https://baseer.moath1777.workers.dev --remote`. يتطلب صلاحيات Wrangler على قاعدة البيئة المستهدفة، وينشئ بيانات اصطناعية ثم يحذفها مع إبقاء سجل التدقيق. لا تشغله على بيئة مختلفة دون مطابقة إعداد قاعدة البيانات مع الرابط.

مراجع التنفيذ: [OpenNext bindings](https://opennext.js.org/cloudflare/bindings)، [معاملات D1 batch](https://developers.cloudflare.com/d1/worker-api/d1-database/).
