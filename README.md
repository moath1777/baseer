# بصير | Baseer

تطبيق Next.js لإدارة الاستراتيجية والأداء المؤسسي. التسليم الحالي هو **نموذج تجربة الاستخدام للمرحلة M1**، مبني على العرض ذي العشرين شريحة وخارطة الطريق المعتمدة للعمل.

## التشغيل

المتطلبات: Node.js 24 وnpm.

```bash
npm ci
npm run dev
```

افتح [مساحة العمل المحلية](http://127.0.0.1:3000/overview).

```bash
npm run typecheck
npm test
npm run build
npm start
```

`npm start` يشغل ناتج البناء محليًا بعد نجاح `npm run build`. لا يحتاج النموذج الحالي إلى مفاتيح خدمات أو قاعدة بيانات.

## النشر على Cloudflare

الرابط المنشور: [بصير — مساحة العمل](https://baseer.moath1777.workers.dev/overview).

يستخدم المشروع Cloudflare Workers مع محوّل OpenNext لتشغيل صفحات Next.js الديناميكية، بما فيها بطاقات المؤشرات التي ينشئها المستخدم.

```bash
npm run build:cloudflare
npm run preview:cloudflare
```

في إعدادات البناء المرتبطة بمستودع `moath1777/baseer`:

- الفرع: `main`.
- أمر البناء: `npm run build:cloudflare`.
- أمر النشر: `npm run deploy:cloudflare`.
- مجلد المشروع: جذر المستودع.

للنشر اليدوي، سجّل الدخول باستخدام `npx wrangler login`، ثم شغّل أمر البناء وبعده أمر النشر. ملف `wrangler.jsonc` يحدد اسم Worker والحساب والأصول. لا يتطلب النموذج الحالي R2 أو قاعدة بيانات أو أسرارًا.

النشر يعرض نموذج M1 نفسه؛ تُحفظ البيانات في متصفح الزائر ولا تنتقل بيانات المعاينة المحلية تلقائيًا إلى الرابط المنشور. ملفات PowerPoint ومخرجات البناء غير مضمّنة في المستودع أو أصول الموقع.

## ما يمكن تجربته الآن

- الرئيسية، الهيكل الاستراتيجي والتنظيمي، قائمة المؤشرات وبطاقاتها، دورة القياس، مركز الموافقات وإعدادات المعاينة.
- التبديل بين نطاق البرنامج والوزارة وثلاث فترات ربع سنوية.
- واجهة عربية RTL وإنجليزية LTR، وتصميم متجاوب يستخدم الشعار المرفق دون تعديل.
- إنشاء مؤشر مستقل أو مركب بأوزان، ومعالج إنشاء من أربع خطوات.
- حفظ مسودة تعريف المؤشر محليًا واستئنافها.
- إدخال قياس وحفظ مسودته وإرساله للمراجعة، ثم الإعادة بتعليق إلزامي أو الاعتماد.
- احتساب النتائج من القيم المعتمدة فقط، وتجميع المؤشر المركب دون تكراره في المتوسط العام.
- البحث والتصفية، وسجل إجراءات محلي، ومعاينة اختلاف الأدوار.

## حدود التسليم

البيانات المعروضة والأسماء أمثلة توضيحية وليست بيانات الجهة. يُحفظ النموذج على الجهاز في `localStorage`، ويعرض تحذيرًا إذا فشل التخزين. بيانات `localhost` منفصلة عن `127.0.0.1` بحسب أصل المتصفح.

معاينة الأدوار **ليست تسجيل دخول ولا صلاحيات خادم**. لا تستخدم النموذج لمعالجة بيانات مؤسسية فعلية أو لاتخاذ قرارات اعتماد رسمية. تُحفظ أسماء المرفقات فقط، دون رفع محتواها أو تخزينه. لا توجد تقارير PDF/Excel/PPT أو تكاملات خارجية بعد.

المعادلات الحالية أمثلة مقترحة للتجربة: اتجاه إيجابي وسلبي ومتوسط موزون لنسب الإنجاز. لا يوجد بعد منشئ معادلات عام أو مؤشر ثنائي القطبية أو مستهدفات مختلفة لكل فترة. الدوريات والمستهدفات في النموذج مبسطة وموثقة في الواجهة. مسار الموافقة تجريبي من مرحلة مراجعة واحدة.

## بنية المشروع

```text
src/app/                 صفحات Next.js والتخطيط والخطوط والهوية
src/components/          مساحة العمل والنماذج والمكونات المشتركة
src/lib/domain.ts        أنواع البيانات وقواعد الحساب وانتقالات القياس
src/lib/seed.ts          البيانات التجريبية
public/mngdp-logo.png    نسخة مطابقة للشعار الذي قدمه المستخدم
tests/domain.test.ts    اختبارات القواعد المهمة
```
