آخر تحديث: 14 أكتوبر 2026.

| المرحلة                        | الحالة                                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| M1 — تحليل المنتج وUX/UI       | مغلقة كخط أساس للتصميم بتوجيه المستخدم. راجع [محضر الإغلاق](M1-CLOSURE.md).               |

| M7 — التكامل والإطلاق المؤسسي  | لم تكتمل؛ الاستضافة الحالية لا تعني قبول الإطلاق المؤسسي.                                 |

## ما أنجز في M2

- التسجيل والدخول بالبريد وكلمة المرور، دون OTP أو إرسال بريد، وفق اختيار المستخدم.
- لا وصول تلقائيًا للحسابات الجديدة. إسناد تسعة أدوار بنطاق جهة ووحدة وتوابعها وتصريح المقيد.
- فصل إدارة الحسابات عن صلاحيات قراءة بيانات الجهات، وفحص الصلاحيات على الخادم في كل طلب.
- إدارة المستخدمين وتعطيلهم وإعادة تعيين كلمة مؤقتة وإبطال الجلسات وتغيير كلمة المرور.
- قاعدة بيانات علائقية مشتركة للوحدات والاستراتيجيات والخطط والأهداف والمبادرات وارتباطات المؤشرات.
- الرؤية والرسالة والقيم والفترات والمسؤوليات والأسماء والأوصاف بالعربية والإنجليزية.
- إضافة وتعديل وحذف وروابط، مع منع الدورات والروابط عبر الجهات وحذف السجلات ذات التبعيات.
- عروض الخريطة والتنظيمي والشجري وملخص أعداد من البيانات المحفوظة نفسها، مع البحث والتصفية.
- حفظ التعديل وسجل قبل/بعد داخل معاملة واحدة، ورفض التحديث المتعارض.
- ملفات الهجرة وأداة إعداد المدير الأول ودليل التشغيل وفحص إعداد قاعدة البيانات قبل النشر.

## نتائج التحقق

| التحقق                      | النتيجة                                                                                                                                              |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| اختبارات القواعد والخدمات   | نجحت 26 حالة: 15 لنموذج M1 و11 لمجالات M2. تشمل حالات M2 اختبارات D1 للعزل والسرية والتزامن والتراجع عن العمليات الفاشلة وثبات سجل التدقيق والجلسات. |
| TypeScript وبناء Cloudflare | نجح فحص الأنواع وبناء OpenNext للإنتاج والنشر.                                                                                                       |
| المتصفح المحلي              | دخول وإنشاء استراتيجية وهدف مرتبط بها، إعادة تحميل والتحقق من ثبات البيانات وعلاقة الأب في الشجرة.                                                   |
| العربية والإنجليزية         | فحص الحاسب والهاتف بعرض 390 وارتفاع 844؛ لا تجاوز أفقي في الصفحات المفحوصة.                                                                          |
| القبول على الموقع العام     | نجح التسجيل والجلسة الآمنة ومنع الإسناد التلقائي وعزل الجهات والإضافة والتعديل والروابط والحذف واستمرار البيانات ورفض التعارض وسجل قبل/بعد والخروج.  |
| حساب المدير                 | نجح الدخول بالحساب المحدد من المستخدم، وظهرت شاشة إلزام تغيير كلمة المرور المؤقتة. ترك اختيار الكلمة الدائمة للمستخدم.                               |
| الاعتماديات                 | لم يبلغ npm audit عن ثغرات وقت الفحص.                                                                                                                |

نفذ اختبار الموقع العام باستخدام حساب وسجلات اصطناعية مؤقتة. حذفت بياناته بعد الاختبار، مع الاحتفاظ بأحداث التدقيق غير القابلة للتعديل. أداة الاختبار: scripts/smoke-deployed.mjs.

## النشر والبيانات

- الرابط: [بصير](https://baseer.moath1777.workers.dev/overview).
- نسخة Cloudflare التي اجتازت التحقق: `53e18579-33e4-4025-a134-b91c909b340c`.
- قاعدة D1: `baseer-m2`؛ الربط `DB` معرف في wrangler.jsonc، والهجرة 0001 مطبقة سحابيًا.
- التطوير يستخدم قاعدة محلية منفصلة؛ لا ترفع البيانات المحلية تلقائيًا.
- أعد حساب المدير الأول وفق بيانات المستخدم، دون تخزين كلمة المرور في المستودع. يتطلب أول دخول تعيين كلمة دائمة.
- نموذج M1 محفوظ في `/preview/overview` ببيانات محلية فقط، ولا يصل إلى قاعدة البيانات التشغيلية.
- تستبعد ملفات PowerPoint وبيانات الدخول وملفات الاختبار المؤقتة من Git.

## إغلاق M2 وحدوده

اكتملت معايير التسليم التقنية لـ M2 ونشرت النسخة واختبرت على الرابط العام. تبقى مراجعة الجهة للسياسات وقبول التشغيل المؤسسي ضمن بوابات المراحل اللاحقة. ربط SSO مؤجل باتفاق المستخدم؛ لا يرسل تسجيل الدخول أو التسجيل أي بريد.

المتبقي خمس مراحل M3–M7. لا تشمل M2 المعادلات والقياسات والموافقات ورفع الأدلة والتقارير الرسمية والتكاملات. توثق [مواصفات M2](M2-IMPLEMENTATION.md) حدود الأدوار والبيانات الحالية.
