# M2 — أساس النظام والهيكل والصلاحيات

تاريخ التنفيذ: 14 أكتوبر 2026. المرجع: ROADMAP.md ومتطلبات v06 ومحضر إغلاق M1.

## القرار التنفيذي

اختيار قاعدة Cloudflare D1 العلائقية لتوافقها مع استضافة Workers الحالية، بدل افتراض مزود PostgreSQL لم يطلبه المستخدم. تستخدم بيئة التطوير محاكي D1 بملفات دائمة داخل .wrangler؛ أنشئت قاعدة السحابة المستقلة وربطت وطبقت هجرتها ونشرت M2. لا تُرفع بيانات محلية تلقائيًا.

طلب المستخدم حسابات بالبريد دون OTP أو رسائل. المنفذ بريد وكلمة مرور؛ لا يتحقق النظام من ملكية البريد، لذلك لا يمنح التسجيل وصولًا تلقائيًا ولا يعتمد نطاق البريد لمنح الأدوار. يسند المدير الوصول بعد التحقق من المستخدم عبر إجراءات الجهة. SSO مؤجل بطلب المستخدم ولا يوصف بأنه متصل.

## البيانات

| الجدول                     | الغرض                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| organizations              | نطاقا البرنامج والوزارة، ورقم إصدار الهيكل لكل جهة                                               |
| users / sessions           | حسابات نشطة/معطلة وكلمات مرور مجزأة ورموز جلسات مجزأة وانتهاء الجلسة                             |
| grants                     | دور وجهة ووحدة اختيارية وإذن الاطلاع على المقيد                                                  |
| nodes                      | وحدة أو استراتيجية أو خطة أو هدف أو ارتباط مؤشر أو مبادرة، مع مفاتيح علاقات وبيانات ثنائية اللغة |
| links                      | روابط إضافية من الأهداف إلى المؤشرات والمبادرات داخل الجهة نفسها                                 |
| audit                      | الفاعل والعملية والتاريخ والقيم قبل/بعد؛ لا يوجد API لتعديله أو حذفه                             |
| rate_limits / write_guards | حد محاولات الدخول ورفض عمليات الحفظ على إصدار قديم                                               |

المفاتيح والعلاقات مقيّدة في SQLite، والحقول الموسعة في JSON تتحقق منها طبقة الخدمة. تعكس الخريطة والتنظيمي والشجري ولوحة الأعداد نفس العقد والروابط. الاستراتيجيات الفرعية هي استراتيجيات مرتبطة باستراتيجية أب. الأهداف التشغيلية تميز بالمستوى، وتربط بالاستراتيجية أو الخطة أو الهدف الأب. بطاقات M3 ستستخدم معرفات ارتباطات المؤشرات نفسها؛ الارتباط ليس معادلة أو قياسًا.

## مصفوفة M2 المنفذة

| الدور                                                                                                | القراءة ضمن النطاق             | تحرير الهيكل                                           |
| ---------------------------------------------------------------------------------------------------- | ------------------------------ | ------------------------------------------------------ |
| مدير النظام                                                                                          | نعم، المقيد يتطلب إذنًا صريحًا | جميع أنواع الهيكل ضمن النطاق                           |
| فريق الاستراتيجية                                                                                    | نعم                            | جميع أنواع الهيكل ضمن النطاق                           |
| فريق الأداء                                                                                          | نعم                            | الخطط والأهداف وارتباطات المؤشرات والمبادرات التشغيلية |
| السفير، مالك المؤشر، إدارات الأداء، المدير العام للأداء، مجموعات الاطلاع، المسؤول الأول للاستراتيجية | نعم                            | لا في M2؛ وظائف القياس والاعتماد الخاصة بهم تتبع M3–M6 |

إدارة الحسابات إذن منفصل عن دور البيانات؛ مدير الحسابات لا يقرأ كل الجهات تلقائيًا. نطاق الوحدة يشمل الوحدات التابعة، ولا يسمح للمحرر المحدود بنقل جذر نطاقه. إخفاء الأزرار ليس آلية الحماية: تعيد طبقة الخدمة التحقق من كل طلب. نطاق المؤشر المسند ومسارات الاعتماد التفصيلية يضافان مع M3–M4، ولا يعني الدور السماح بإجراءات لم تنفذ.

سجل تغييرات الهيكل قد يحتوي سجلات محذوفة أو مقيدة، لذلك يقرأه فقط مدير بيانات كامل الجهة لديه تصريح المقيد. سجل الحسابات متاح لمديري الحسابات. تعرض الواجهة آخر 200 حدث؛ لا تحذف الأحداث الأقدم.

## معايير القبول

- إنشاء وتعديل استراتيجية وخطة وهدف ووحدة وارتباط مؤشر ومبادرة مع بقاء البيانات بعد إعادة التحميل.
- رفض قراءة جهة غير مسندة أو الكتابة بدور قارئ، وحجب الوحدات والسجلات والروابط غير المصرح بها.
- منع الروابط عبر الجهات والدورات والأكواد المكررة والتواريخ غير الصحيحة.
- منع حذف سجل ذي تبعيات أو إسنادات مستخدمين، وتوثيق الإضافة والتعديل والحذف والروابط.
- الحفظ وسجل التدقيق في معاملة واحدة؛ فشلها لا يترك تغييرًا جزئيًا. ترفض الكتابة المتزامنة القديمة بدل الكتابة فوق تغيير مستخدم آخر.
- إبطال الجلسات عند تعطيل الحساب أو تعديل الوصول أو إعادة تعيين كلمة المرور؛ لا يمكن إلغاء آخر مدير نشط.
- فتح البيانات بالعربية والإنجليزية على الحاسب والهاتف، وإتاحة حالات التحميل والفراغ والخطأ.

## الحسابات والتشغيل

إنشاء الحساب لا يرسل بريدًا. وفق تعديل المستخدم، تقبل كلمات المرور أي قيمة غير فارغة من رمز واحد أو أكثر، دون اشتراط نوع الرموز، مع حد 72 بايت الخاص بـ bcrypt؛ تحسب بتكلفة 12. تنطبق القاعدة على التسجيل والتغيير وإعادة التعيين وإعداد المدير. التسجيل بكلمة يختارها المستخدم لا يفرض تغييرها عند أول دخول. ينطبق ذلك أيضًا على إعداد المدير بكلمته المختارة عبر --password-stdin؛ أما الكلمة المولدة تلقائيًا أو المعاد تعيينها من المسؤول فتبقى مؤقتة وتتطلب التغيير. الجلسات عشوائية ومخزنة مجزأة وتنتهي بعد 8 ساعات، مع HttpOnly وSameSite=Lax وSecure على HTTPS. طلبات التعديل تتطلب أصل الموقع نفسه. يستعيد المدير الوصول بكلمة مؤقتة تجبر صاحب الحساب على تغييرها، دون بريد.

لا توجد حسابات افتراضية عامة. ينشئ المشغل المدير الأول بأداة admin:bootstrap، وتذهب بياناته المؤقتة إلى ملف محلي مستبعد من Git. بيانات الاختبارات اصطناعية؛ اختبار القبول السحابي يحذف حسابه وسجلاته المؤقتة بعد الانتهاء ويحتفظ بأحداث التدقيق.

## تحسينات إدارة الحسابات والنوافذ

- حذف الحساب متاح لمدير الحسابات فقط مع نافذة تأكيد تعرض الاسم والبريد؛ يمنع حذف الحساب الحالي وآخر مدير نشط.
- يحفظ الحذف وسجله في عملية واحدة، وتلغى الجلسات والصلاحيات التابعة. تبقى بيانات العمل وأحداث التدقيق السابقة محفوظة.
- الهجرة 0002 تضيف منع حذف آخر مدير نشط على مستوى قاعدة البيانات.
- هوامش موحدة لنوافذ إدارة الوصول والإضافة والتفاصيل وتأكيد الحذف، مع ترتيب الأزرار والتفاف العناوين والحقول على الهاتف بالعربية والإنجليزية.

## التحقق وحدود التسليم

تعتمد اختبارات M2 على محاكي D1 حقيقي، وتشمل الأدوار والعزل والسرية والدورات والمعاملات المتزامنة والسجل والجلسات وحد المحاولات. حالة نتائج البناء واختبارات المتصفح والنشر في IMPLEMENTATION-STATUS.md.

لا تشمل M2 رفع المرفقات الفعلي أو القياسات أو محرك المعادلات أو الموافقات أو التقارير الرسمية. تعرض الصفحة العامة /preview نموذج M1 المحلي منفصلًا عن البيانات الفعلية. موافقة الإنتاج المؤسسي والأحمال والاستعادة والتكاملات ضمن M7؛ لا يعتبر اختبار محلي إثباتًا للنشر السحابي.
